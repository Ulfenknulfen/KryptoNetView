KryptoNetView


🇬🇧 KryptoNetView (English)
An offline-first, single-file HTML network topology application featuring zero-knowledge AES-256 encryption, an interactive SVG canvas, and bilingual support (German/English).

📸 Preview
Main Topology View
Detail View / Gateway Configuration
🚀 Key Features
🌍 Platform-Independent: Runs on any modern operating system (Windows, macOS, Linux, ChromeOS, etc.) without installation or additional runtime environments.

🇩🇪 / 🇬🇧 Fully Bilingual: Seamless, instant switching between German and English user interfaces with a single click.

🔐 Zero-Knowledge Security: All data is securely encrypted directly in your browser using AES-256 (AES-GCM) via the Web Crypto API, protected by a master password derived via PBKDF2. No cloud, no tracking, no backend server.

🗺️ Interactive SVG Canvas: Smooth, draggable network nodes, custom zones/frames, dynamic connection lines, zoom/pan controls, and real-time visual feedback.

📂 Single-File Portability: Built as a single, self-contained HTML file. No database setup or external dependencies required—just open it in any browser.

⚙️ Dynamic Device & Category Management: Manage routers, gateways, WLAN access points (with SSID configurations), switches, servers, and endpoints with customizable categories and status indicators.

💾 Secure Backup & Restore: Export and import your encrypted network configuration safely via JSON files.

🛡️ Security Model & Privacy
KryptoNetView follows a strict Zero-Knowledge Architecture:

No Password Recovery: Because there is no server or database, password resets are technically impossible. If you lose your master password, your encrypted data cannot be recovered. You hold 100% of the responsibility and 100% of the control.

Local Execution: All cryptographic operations run strictly client-side inside your browser sandbox.

🛠️ Quick Start
Download or clone the repository:

Bash
git clone https://github.com/ulfenknulfen/kryptonetview.git
Open kryptonetview.html (the ready-to-use application) or yourproject.html (the clean starting template) directly in any modern web browser (Chrome, Firefox, Edge, Safari).

Click Login to unlock the administrator vault, customize your network topology, and export your secure configuration.

Eine autarke Single-File-HTML-Netzwerktopologie-Anwendung mit integrierter Zero-Knowledge-AES-256-Verschlüsselung, interaktiver SVG-Oberfläche und vollständiger Zweisprachigkeit (Deutsch/Englisch).

🚀 Hauptmerkmale
🌍 Plattformunabhängig: Läuft auf jedem modernen Betriebssystem (Windows, macOS, Linux, ChromeOS etc.) ohne Installation oder zusätzliche Laufzeitumgebungen.

🇩🇪 / 🇬🇧 Vollständig Zweisprachig: Nahtloser, sofortiger Wechsel zwischen deutscher und englischer Benutzeroberfläche per Klick.

🔐 Zero-Knowledge-Sicherheit: Alle Daten werden direkt im Browser mittels AES-256 (AES-GCM) über die Web Crypto API verschlüsselt und durch ein per PBKDF2 abgeleitetes Master-Passwort geschützt. Keine Cloud, kein Tracking, kein Backend-Server.

🗺️ Interaktive SVG-Zeichenfläche: Fließend verschiebbare Netzwerkknoten, benutzerdefinierte Zonen/Rahmen, dynamische Verbindungslinien, Zoom-/Schwenk-Steuerung und visuelles Echtzeit-Feedback.

📂 Single-File-Portabilität: Als eine einzige, in sich geschlossene HTML-Datei aufgebaut. Keine Datenbankeinrichtung oder externe Abhängigkeiten erforderlich – einfach in jedem modernen Browser öffnen.

⚙️ Dynamische Geräte- und Kategorienverwaltung: Verwaltung von Routern, Gateways, WLAN-Access-Points (inkl. SSID-Konfigurationen), Switches, Servern und Endpunkten mit anpassbaren Kategorien und Statusindikatoren.

💾 Sichere Datensicherung & Wiederherstellung: Exportieren und Importieren der verschlüsselten Netzwerkkonfiguration sicher über JSON-Dateien.

🛡️ Sicherheitsmodell & Datenschutz
KryptoNetView folgt einer strengen Zero-Knowledge-Architektur:

Keine Passwortwiederherstellung: Da kein Server oder eine Datenbank existiert, ist ein Zurücksetzen des Passworts technisch unmöglich. Wenn Sie Ihr Master-Passwort verlieren, können Ihre verschlüsselten Daten nicht wiederhergestellt werden. Sie tragen 100 % der Verantwortung und haben 100 % der Kontrolle.

Lokale Ausführung: Alle kryptografischen Operationen laufen strikt clientseitig in Ihrer Browser-Sandbox ab.
